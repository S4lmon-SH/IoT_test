## 지금 필요한 물리 작업

1. UNO R4 WiFi의 USB 단자를 확인한다.
2. USB-C 케이블로 PC와 보드를 연결한다.
3. DHT11의 앞면과 뒷면, 핀 글자가 보이는 사진을 찍는다.
4. 아직 센서 전원은 연결하지 않는다.

보드를 연결한 뒤 PowerShell에서 다음 명령으로 포트를 확인한다.

```powershell
cd "C:\Users\markj\Desktop\대전대 4학년\아두이노\room-monitor"
powershell -ExecutionPolicy Bypass -File .\scripts\list_arduino_boards.ps1
```

`COM5`처럼 표시되는 포트 이름이 필요하다.

## 펌웨어에 입력해야 하는 정보

[`firmware/room_monitor/arduino_secrets.h`](firmware/room_monitor/arduino_secrets.h)에서 다음 두 값만 아직 비어 있다.

```cpp
#define WIFI_SSID "YOUR_WIFI_NAME"
#define WIFI_PASSWORD "YOUR_WIFI_PASSWORD"
```

Wi-Fi 비밀번호를 대화에 적을 필요는 없다. 파일을 PC에서 직접 수정하면 된다. 현재 서버 주소는 이 PC의 Wi-Fi 주소 `192.168.45.124:8000`으로 미리 설정되어 있다.

## 현재 남은 설정

[`firmware/room_monitor/arduino_secrets.h`](firmware/room_monitor/arduino_secrets.h)의 Oracle 서버 주소와 장치 API 키는 이미 설정됐다. 다음 명령을 실행하면 Wi-Fi 이름과 비밀번호를 안전하게 입력할 수 있다.

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\set_wifi_credentials.ps1
```

비밀번호는 입력할 때 화면에 보이지 않으며 대화로 공유할 필요가 없다. 저장한 뒤 보드가 연결된 `COM3`에 펌웨어를 업로드한다.

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\upload_firmware.ps1 -Port COM3
powershell -ExecutionPolicy Bypass -File .\scripts\monitor_serial.ps1 -Port COM3
```
