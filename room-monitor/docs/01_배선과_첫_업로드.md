# DHT11 배선과 첫 업로드

처음에는 **DHT11만 연결**한다. LCD와 PIR은 서버 전송이 성공한 뒤 추가한다.

## 준비물

- Arduino UNO R4 WiFi
- DHT11 온습도 센서
- 점퍼 와이어 3개
- 브레드보드
- USB-A to USB-C 케이블 또는 USB-C to USB-C 케이블

## DHT11이 3핀 모듈인 경우

센서 기판에 `S`, `+`, `-` 또는 `DATA`, `VCC`, `GND`가 인쇄되어 있는지 확인한다.

| DHT11 | UNO R4 WiFi |
|---|---|
| `S` 또는 `DATA` | `D2` |
| `+` 또는 `VCC` | `5V` |
| `-` 또는 `GND` | `GND` |

센서마다 핀 순서가 다를 수 있으므로 왼쪽부터 무조건 꽂지 말고 **기판에 인쇄된 글자를 기준으로 연결**한다.

## DHT11이 기판 없는 4핀 단품인 경우

4핀 단품은 DATA와 VCC 사이에 보통 10kΩ 풀업 저항이 필요하다. 현재 가진 부품에 저항이 있는지 먼저 확인하고, 핀 배열은 센서 정면 기준 데이터시트와 대조한다. 사진 확인 전에는 전원을 연결하지 않는다.

## 나중에 PIR을 추가하는 경우

| HC-SR501 | UNO R4 WiFi |
|---|---|
| `OUT` | `D3` |
| `VCC` | `5V` |
| `GND` | `GND` |

PIR을 연결한 뒤 `arduino_secrets.h`의 다음 값을 바꾼다.

```cpp
#define ENABLE_PIR 1
```

전원을 넣은 직후 PIR이 안정화되는 동안 약간의 시간이 필요하며, 가만히 있는 사람을 계속 감지하는 센서는 아니다.

## Arduino IDE 설정

1. Arduino IDE를 실행한다.
2. 보드 관리자에서 `Arduino UNO R4 Boards`를 설치한다.
3. 라이브러리 관리자에서 `DHT sensor library`를 설치한다.
4. 의존성 설치 질문이 나오면 모두 설치한다.
5. `firmware/room_monitor/room_monitor.ino`를 연다.
6. 보드를 `Arduino UNO R4 WiFi`로 선택한다.
7. 보드가 연결된 COM 포트를 선택한다.
8. `arduino_secrets.h`에 Wi-Fi와 서버 정보를 입력한다.
9. 확인 버튼으로 컴파일한 뒤 업로드한다.
10. 시리얼 모니터를 열고 속도를 `115200 baud`로 설정한다.

정상이라면 다음과 비슷한 문장이 1분마다 출력된다.

```text
측정값: 24.8 °C, 57.0 %, 움직임: 없음
서버 연결: sensor.example.com:443
서버 응답: HTTP 201
```

`HTTP 201`이 서버 저장 성공을 의미한다.
